# App Droguería - Taller 2

Aplicación web desarrollada en Angular para la gestión de inventario de medicamentos.

## 🚀 Enlace del Proyecto Desplegado

[Ver aplicación en vivo](https://espinelcaceresmariafernanda-svg.github.io/drogueria-app/)

## 🛠️ Tecnologías Utilizadas

- Angular
- TypeScript
- HTML5 / CSS3
- GitHub Pages (Despliegue)

## 📌 Funcionalidades Principales

- Formulario de registro de medicamentos.
- Visualización de inventario.
- Persistencia de datos local.
- Diseño responsivo para dispositivos móviles y de escritorio.
